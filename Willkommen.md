# Knowledge Garden

**Projektwissen erhalten. Quellen verbinden. Das Wissensmodell weiterentwickeln.**

Dieser Garten zeigt einen vollständigen Durchlauf mit deutschen Quellen zur digitalen Teilhabe älterer Menschen.

1. **Ansehen:** [[wiki/index|Den fertigen Garten öffnen]].
2. **Vorführen:** [[demo/ABLAUF|Die Demo in etwa zwölf Minuten zeigen]].
3. **Verstehen:** [[ONTOLOGY|Das Wissensmodell ansehen]].
4. **Prüfen:** [[protokolle/DEMO-PRUEFBERICHT|Den tatsächlichen Prüfbericht lesen]].
5. **Erweitern:** [[prompts/01-QUELLE-EINARBEITEN|Ein weiteres Dokument mit einem KI-Agenten einarbeiten]].

## Was die Demo zeigt

| Schritt | Was passiert? | Was bleibt sichtbar? |
|---|---|---|
| 1 · Ausgangspunkt | Zwei Quellen füllen Ontologie 1.0.0. | Projekte, Maßnahmen, Erkenntnisse und Belege. |
| 2 · Neue Quelle | Eine Evaluation ergänzt einen dritten Projektkontext. | Bestehende Maßnahmen erhalten weitere Belege. Das Modell bleibt gleich. |
| 3 · Modelllücke | Ein Leitfaden verlangt eine Zuordnung von Barrieren zu Maßnahmen. | Das alte Modell weist die Extraktion ab. |
| 4 · Modellerweiterung | Die Demo übernimmt den Typ „Barriere“ und zwei Beziehungen. | Eine zuvor nicht unterstützte Frage erhält eine belegte Antwort. |

> Die Fachprüfung steht aus. Die Quellen sind echt. Die Modellentscheidung in Schritt 4 ist eine ausdrücklich gekennzeichnete Simulation.
